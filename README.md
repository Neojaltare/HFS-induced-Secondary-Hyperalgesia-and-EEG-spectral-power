# README

This repository contains code associated with an ongoing project investigating changes in EEG spectral power induced by secondary hyperalgesia following High-Frequency Stimulation (HFS).

The analyses are conducted on two independent datasets from separate experiments and aim to:

1. Assess whether HFS induces consistent changes in EEG spectral power across both datasets.  
2. Evaluate whether these spectral changes are associated with the extent of induced hyperalgesia.

The analyses are performed both before and after applying a surface Laplacian transformation to the EEG data, in order to assess whether the observed spectral changes likely originate from neural sources close to the scalp (e.g., S1/S2).
